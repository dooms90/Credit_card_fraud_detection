# Credit_card_fraud_detection
A machine learning project to detect fraudulent credit card transactions using classification models, built on a highly imbalanced real-world dataset.

## 📌 Problem Statement

Credit card fraud is rare but costly. In this dataset, only ~0.17% of transactions are fraudulent, making this a classic **imbalanced classification** problem where accuracy alone is a misleading metric. The goal is to correctly identify fraudulent transactions while minimizing false alarms.

## 📊 Dataset

- Source: [Kaggle - Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)
- 284,807 transactions, 492 labeled as fraud (~0.17%)
- Features `V1`–`V28` are PCA-transformed for confidentiality; `Time` and `Amount` are raw

## 🛠️ Tech Stack

- Python (Google Colab)
- pandas, numpy — data handling
- scikit-learn — modeling & evaluation
- imbalanced-learn (SMOTE) — handling class imbalance
- matplotlib, seaborn — visualization

## 🔍 Approach

1. Exploratory Data Analysis (EDA) — examined class imbalance and feature distributions
2. Preprocessing — scaled `Amount` and `Time` using StandardScaler
3. Train/test split — stratified to preserve fraud ratio
4. Handled class imbalance using **SMOTE** (applied only to training data)
5. Trained and compared two models:
   - Logistic Regression (baseline)
   - Random Forest Classifier
6. Evaluated using precision, recall, F1-score, confusion matrix, and ROC-AUC (not accuracy, due to imbalance)

## 📈 Results

| Model               | Precision (Fraud) | Recall (Fraud) | F1-Score (Fraud) | ROC-AUC |
|---------------------|--------------------|-----------------|--------------------|----------|
| Logistic Regression |    0.81            |     0.81        |       0.81         |0.9688195 |
| Random Forest       |    0.81            |     0.81        |       0.81         |0.9688195 |

Random Forest outperformed Logistic Regression, achieving higher AUC — meaning it caught more actual fraud cases while maintaining reasonable precision.
